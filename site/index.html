Compare SIMD on your own machine.

Measure ordinary and vectorized Go operations on generated arrays. Open a local browser panel to run a comparison, inspect the repeats, and keep the report.

Get SIMD Lab ↓ Read the quick start

Download and open

Look for Windows amd64 ZIP or Linux amd64 tar.gz builds and their SHA-256 checksums on GitHub Releases.

View GitHub Releases →

Run the local app

Extract the archive, open a terminal in that folder, and launch the included executable.

Windows PowerShell.\simdlab.exe ui

Linux./simdlab ui

Use the CLI or build from source

The CLI runs the same comparison over SSH or from a script. Both workflows save measurements on the measuring machine.
